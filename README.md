# Deutsch Lernen — أداة تعلم الألمانية

Interactive German-learning app for Arabic speakers, inspired by Linga, Germanize and German-dictionary apps.

- Step-by-step path A1→A2: 5 units, 15 lessons, 120+ words and phrases
- Every item with Arabic-script pronunciation + real German audio (TTS)
- 6 exercise types per lesson: multiple choice, listening, writing (ä/ö/ü/ß), sentence ordering, microphone pronunciation scoring
- Smart conversation trainer: guided dialogues (café, introductions, train station) with mistake correction
- Flashcards with review system, auto-corrected dictation, 7 grammar topics, XP & stars

Open `index.html` in a browser (or via GitHub Pages) — no build step, no server needed.
Progress is kept for the session; microphone pronunciation needs a browser with speech recognition (e.g. Chrome).
